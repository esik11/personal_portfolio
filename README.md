# Jeorge Andrei portfolio

Plain HTML, CSS and JavaScript. No build step: open `index.html` or upload the folder to GitHub Pages / Netlify.

## Things to replace
- **Side projects** (`projects.html`, section `#side-projects`): each card is one `<a class="side-card">`. Edit the title, text, numbers and `href="#"`. For a real thumbnail, add `<img src="images/side/name.jpg" alt="">` as the first child of `.thumb`. Delete the "Sample content" notice when done. Copy a card to add more.
- **Contact details**: search for `your.email@example.com` and the `github.com`, `linkedin.com`, `facebook.com` links in the footer of every page.
- **Your photo**: `about.html`, the `.avatar` block.
- **Clock timezone**: `script.js`, search `Asia/Manila`.
- **Colors**: the `:root` blocks at the top of `styles.css`.

Fonts are self-hosted in `fonts/` (Bricolage Grotesque and Instrument Sans, both SIL OFL).
